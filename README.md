# ZEN — 心の庵

AIとの対話を通じて、日常の悩みや迷いを言葉にし、禅の考え方を参考にしながら自分自身を見つめ直すためのWebアプリケーションです。

## 概要

**ZEN — 心の庵**（ZEN REFLECTIONS）は、悩みや迷いを抱える人が、自分の気持ちや状況を落ち着いて振り返るきっかけを提供する個人開発プロジェクトです。

単に行動を指示したり、正解を押しつけたりするのではなく、ユーザーの気持ちに寄り添い、内省につながる対話を目指しています。

- AIによる相談内容のトピック分類・要約
- プレミアムプランでの過去の相談要約を活用した対話
- 個人情報と思われる記述の検出と、伏せ字にした相談文の提案
- 日本語・英語に対応したインターフェース

企画・設計・実装から、テスト、本番環境へのデプロイ・運用まで一貫して開発しています。

## 主な機能

- **AIによる悩み相談：** OpenAI APIを活用し、禅の視点から自分の気持ちや状況を見つめ直すための対話
- **ユーザー認証：** ユーザー登録・ログイン、Googleログイン
- **相談データ管理：** 相談に関連するデータの保存・管理
- **過去の相談の活用：** トピック分類と要約を用いた、過去の相談を踏まえた応答
- **個人情報への配慮：** 個人情報と思われる記述を検出し、送信前の注意喚起と伏せ字の提案
- **多言語対応：** 日本語・英語のインターフェース
- **プラン管理：** Stripeを利用した決済と、Webhookによる契約状態の管理

## ローカル開発環境

### 必要な環境

- PHP 8.3+
- Composer
- Node.js / npm
- MySQL または SQLite（アプリケーションの設定に応じて選択）
- OpenAI APIキー

### セットアップ手順

1. リポジトリをクローンします。

   ```bash
   git clone https://github.com/TakahiroNago/zen-app.git
   cd zen-app
   ```

2. PHPの依存関係をインストールします。

   ```bash
   composer install
   ```

3. 環境設定ファイルを作成します。

   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

4. `.env` にデータベース接続情報や必要なAPIキーなどを設定します。

5. データベースのマイグレーションを実行します。

   ```bash
   php artisan migrate
   ```

6. フロントエンドの依存関係をインストールし、アセットをビルドします。

   ```bash
   npm ci
   npm run build
   ```

7. 開発サーバーを起動します。

   ```bash
   php artisan serve
   ```

詳細な設定は、`.env.example` および各種設定ファイルを参照してください。

## セキュリティと利用上の注意

- APIキーやデータベース認証情報などの秘密情報は環境変数で管理します。
- `.env` や秘密情報を含むファイルを公開リポジトリにコミットしないようにします。
- AIによる回答は内省支援を目的としており、医療・法律・金融などの専門的判断を代替するものではありません。
- AIの回答は必ずしも正確とは限りません。
